#### Part 2: Linux Troubleshooting Matrix

| Troubleshooting Scenario | Diagnostic Check | Functional Mechanics & Purpose | Syntax & Example Usage | Operational Notes & Constraints | Linux / MacOS | Debian / RH Differences |
| ------ | ------ | ------ | ------ | ------ | ------ | ------ |
| **1. CPU is 100%** | Check running process | Identifies top processes consuming CPU cycles. | top<br><br>htop<br><br>ps aux --sort=-%cpu \| head | Allows identifying runaway processes and interactive thread viewing. | Both | Process inspection tools (`top`, `ps`, `htop`) operate identically across Debian and RHEL. |
| **2. | **4. | **8. | **10. | **11. | **12. Tracing hanging or slow processes** | Trace process system calls | Attaches to a running process ID to observe real-time system call execution. | strace -p PID | Deep system diagnostic for identifying stuck I/O operations or blocked syscalls. | Linux only | System call tracer (`strace`) operates identically across Debian and RHEL. |

#### Part 8: SysAdmin Operational Rules & Best Practices (Pro Tips Matrix)

| Operational Rule / Best Practice | Scope / Category | Functional Mechanics & Purpose | Syntax & Implementation | Strategic Value & Risk Mitigation | Environment | Debian / RH Differences |
| ------ | ------ | ------ | ------ | ------ | ------ | ------ |
| **Validate SSH Config Before Reload** | Service Safety | Tests SSH daemon configuration syntax for errors prior to restarting the service daemon. | sshd -t && systemctl reload sshd | Prevents locking administrators out of remote servers due to syntax errors. | Linux / BSD | Debian service is `ssh` or `sshd` (`systemctl reload ssh`).
